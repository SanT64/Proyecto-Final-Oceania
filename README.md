**Proyecto:** ExpoDIT · Noviembre 2026  
**Asignatura:** Gráficos, Interfaces y Usabilidad

## 📖 ¿Qué es OCEANÍA?

OCEANÍA es una plataforma web educativa e interactiva dirigida principalmente a niñas y niños de 6 a 10 años. La idea del proyecto es que puedan conocer más sobre la vida marina, descubrir algunas de las especies que habitan en nuestros océanos y aprender por qué es importante cuidarlos.

Para desarrollar el contenido tomamos como referencia el Sistema Arrecifal Veracruzano, del cual seleccionamos diez especies que forman parte de las diferentes actividades de la página.

También buscamos que la plataforma pudiera ser utilizada por personas con diferentes necesidades, por lo que durante su desarrollo incorporamos distintas opciones de accesibilidad.

## 🌊 ¿Qué puedes encontrar en la plataforma?

### Exploración de especies

En este apartado se pueden conocer las diez especies seleccionadas mediante fichas informativas que incluyen:

- Nombre común y nombre científico.
- Categoría de protección según la NOM-059-SEMARNAT-2010, cuando corresponde.
- Ilustraciones y fotografías reales.
- Narración por voz para escuchar la información.

### Mundos submarinos

Creamos cuatro espacios que representan diferentes entornos marinos. En cada uno se pueden explorar e interactuar con distintos elementos del ecosistema.

- **Reino de los arrecifes**
- **Océano infinito**
- **Jardín submarino**
- **Mundo de las rocas**

También se incluyen pistas y pequeños retos para que los niños puedan descubrir más sobre los animales y los lugares donde viven.

### Misión de Guardianes

Es un minijuego en el que los niños deben identificar residuos que contaminan el océano y conocer cómo afectan a la vida marina.

Conforme avanzan pueden conseguir tres insignias: Observador, Protector y Guardián. La actividad no tiene límite de tiempo ni penalizaciones, por lo que pueden realizarla a su propio ritmo.

### Opciones de accesibilidad

Uno de los aspectos que consideramos durante el desarrollo fue facilitar el uso de la página para personas con diferentes necesidades. Para ello agregamos:

- Modos de visualización para Protanopía, Deuteranopía, Tritanopía y Acromatopsia.
- Opción para pausar las animaciones.
- Transcripciones de audio.
- Navegación mediante teclado.
- Indicadores de foco y acceso directo al contenido.
- Diseño adaptable a diferentes tamaños de pantalla.
- Formulario para reportar problemas de accesibilidad.
- Declaración de accesibilidad.

Estas herramientas se desarrollaron tomando como referencia los criterios WCAG 2.2 Nivel AA.

## 🎯 Relación con los ODS

OCEANÍA se relaciona con tres Objetivos de Desarrollo Sostenible:

- **ODS 4 – Educación de calidad:** buscamos acercar la educación ambiental a los niños desde una edad temprana.
- **ODS 14 – Vida submarina:** promovemos el conocimiento de las especies marinas y la importancia de proteger sus ecosistemas.
- **ODS 6 – Agua limpia y saneamiento:** fomentamos el cuidado del agua y la prevención de la contaminación.

## 🛠️ Tecnologías utilizadas

Para desarrollar la plataforma utilizamos las siguientes tecnologías:

- **React 19:** para construir la interfaz de usuario.
- **TypeScript:** para trabajar con código tipado.
- **Vite:** para el entorno de desarrollo y compilación.
- **Tailwind CSS:** para los estilos de la página.
- **Vercel:** para publicar la plataforma en línea.

## 🚀 Cómo ejecutar el proyecto

Si deseas ejecutar OCEANÍA en tu equipo, sigue estos pasos:

**1. Clona el repositorio**

```bash
git clone https://github.com/TU-USUARIO/TU-REPOSITORIO.git
```

**2. Entra a la carpeta del proyecto**

```bash
cd TU-REPOSITORIO
```

**3. Instala las dependencias**

```bash
npm install
```

**4. Inicia el servidor de desarrollo**

```bash
npm run dev
```

Después de ejecutar el comando, Vite mostrará la dirección local desde la que podrás abrir la página en tu navegador.

Si deseas generar la versión de producción, puedes utilizar:

```bash
npm run build
```
